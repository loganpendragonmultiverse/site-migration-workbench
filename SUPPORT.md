# Support

This is an unreleased candidate. See docs/ACCEPTANCE.md for its exact state. Linux container testing does not establish native Windows/macOS support. Authentication, JS rendering, general crawling, CMS edits, DNS cutover and production deployment are outside scope.

For a reproducible defect, supply a minimal synthetic inventory, Python/OS version, steps, expected and actual result, and a redacted report. Keep the original backup private. Never include client credentials.
